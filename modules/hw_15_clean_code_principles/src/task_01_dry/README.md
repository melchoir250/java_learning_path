# Задача 1: Исправление нарушения DRY

## Описание проблемы

Исходный код нарушает принцип DRY (Don't Repeat Yourself):

- Три метода делают одно и то же — складывают числа
- Код сложения повторяется в каждом методе
- При изменении логики сложения пришлось бы менять все три метода

## Исходный код

```java
public class MathOperations {
    public int add(int a, int b) {
        return a + b;
    }

    public int addThreeNumbers(int a, int b, int c) {
        return a + b + c;
    }

    public int addFourNumbers(int a, int b, int c, int d) {
        return a + b + c + d;
    }
}
```

## Задача

Устраните дублирование кода, применив перегрузку методов или использование массива аргументов.

## Требования

- Метод должен принимать любое количество чисел
- Использовать перегрузку методов или varargs (переменное количество аргументов)
- Не должно быть дублирования логики сложения
- Метод должен корректно обрабатывать пустой массив (вернуть 0)
