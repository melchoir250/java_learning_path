# Задача 4: Исправление нарушения SRP

## Описание проблемы

Исходный код нарушает принцип SRP (Single Responsibility Principle):

- Класс `Order` выполняет несколько различных задач
- Обработка заказа, отправка email и генерация счета — это разные обязанности
- При изменении логики email-уведомлений придется менять класс заказа
- Класс трудно тестировать, так как он зависит от нескольких систем

## Исходный код

```java
public class Order {
    public void processOrder() {
        System.out.println("Обрабатываем заказ...");
    }

    public void sendEmailConfirmation() {
        System.out.println("Отправляем письмо клиенту...");
    }

    public void generateInvoice() {
        System.out.println("Генерируем счет...");
    }
}
```

## Задача

Разделите класс `Order` на отдельные классы, каждый из которых выполняет только одну задачу.
