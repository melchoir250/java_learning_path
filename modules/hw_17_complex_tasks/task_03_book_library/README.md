# Задача 3: Библиотека для виртуальной библиотеки книг

## Описание

Создать библиотеку, которая предоставляет функции просмотра каталога книг, чтения книг и загрузки их для офлайн-чтения,
с особым вниманием к ленивой загрузке и эффективному управлению ресурсами.

## Паттерны проектирования

| Паттерн | Назначение |
|---------|------------|
| **Proxy** | Lazy Loading Proxy — отложенная загрузка книг, снижение начальной нагрузки на систему |
| **Builder** | Построение сложных объектов книг с различными компонентами (обложка, описание, содержание, авторы) |

## Архитектура библиотеки

| Компонент | Описание |
|-----------|----------|
| `Book` | Базовый класс книги: основная информация и методы доступа |
| `BookBuilder` | Builder для создания книг с различными характеристиками |
| `BookProxy` | Proxy: управляет доступом к `Book`, загружает данные только по необходимости |

## Требования

1. **`Book`**: поля `title`, `author`, `description`, `content`; геттеры для доступа к данным
2. **`BookBuilder`**: fluent-методы `setTitle()`, `setAuthor()`, `setDescription()`, `setContent()` и `build()`
3. **`BookProxy`**: принимает `Book` в конструкторе; содержимое (`content`) загружается только при первом вызове `getContent()`
4. При повторных вызовах `getContent()` загрузка не выполняется повторно

## Пример использования

```java
// Создание книги через Builder
BookBuilder builder = new BookBuilder();
Book book = builder.setTitle("War and Peace")
        .setAuthor("Leo Tolstoy")
        .setDescription("A historical novel about the Napoleonic Wars.")
        .build();

// Инициализация Proxy для ленивой загрузки
BookProxy proxy = new BookProxy(book);

// Доступ к содержимому через Proxy — загрузка только при первом обращении
String content = proxy.getContent();
System.out.println("Content of the book: " + content);
```
