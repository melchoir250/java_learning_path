# Задача 3: Фабричный метод для транспортных средств

## Описание

В этом приложении нам нужно создать систему для создания различных типов транспортных средств (например, автомобили и
велосипеды). Вместо того чтобы код зависел от конкретных классов (например, Car и Bicycle), мы будем использовать
фабричный метод для создания объектов. Это позволит расширять систему, добавляя новые типы транспортных средств, не
меняя существующий код.

## Требования

1. **Интерфейс `Transport`**: Создать интерфейс, который будет представлять общий контракт для всех транспортных
   средств. Это позволит работать с любым типом транспорта одинаково

2. **Конкретные классы `Car` и `Bicycle`**: Эти классы будут реализовывать интерфейс `Transport`. Каждый класс будет
   предоставлять свою реализацию методов

3. **Фабричный метод в классе `TransportFactory`**: Класс фабрики будет иметь метод `createTransport()`, который будет
   возвращать объект типа `Transport`. Этот метод будет абстрактным, и конкретные фабрики (например, `CarFactory` и
   `BicycleFactory`) будут предоставлять свою реализацию метода
