# Задача 7: Builder для создания заказов в интернет-магазине

## Описание

В интернет-магазине клиент может оформить заказ, добавляя товары, указывая скидку и выбирая способ оплаты. Паттерн
Builder поможет организовать процесс формирования заказа, не перегружая конструктор класса `Order` множеством
параметров. Это позволяет строить объекты заказов поэтапно, добавляя товары, скидки и способы оплаты по мере
необходимости.

## Требования

1. **Класс `Order`**: Этот класс представляет конечный объект, который будет хранить все детали заказа, такие как
   товары, скидка и способ оплаты

2. **Класс `OrderBuilder`**: Этот класс будет строить объект `Order`. Он будет предоставлять методы для добавления
   товаров, применения скидки и выбора способа оплаты. Каждый метод будет возвращать сам объект строитель, чтобы
   поддерживать цепочку вызовов (fluent interface)

3. **Класс `Shop`**: Класс магазина, который будет использовать строитель для создания заказов. Он будет использовать
   `OrderBuilder` для построения заказов, не заботясь о конкретной реализации
