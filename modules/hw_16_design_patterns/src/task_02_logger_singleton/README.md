# Задача 2: Singleton для менеджера логирования (Logger)

## Описание

В приложении необходимо создать класс `Logger`, который будет вести журнал событий. Класс должен обеспечивать
централизованный доступ к логированию для всего приложения.

Например:

- Запись информации о событиях (например, успешное подключение к базе данных)
- Запись ошибок (например, исключения при выполнении операций)
- Запись предупреждений (например, при попытке работы с устаревшими методами)

Класс `Logger` должен быть реализован по паттерну Singleton, чтобы в приложении был только один экземпляр этого класса,
который будет использоваться для записи логов.

## Требования

1. **Единственный экземпляр**: В системе должен быть только один экземпляр `Logger`, который создаётся при первом вызове
   метода `getInstance()`

2. **Глобальный доступ**: Логгер должен быть доступен из любой части программы, где необходимо записывать события или
   ошибки

3. **Приватный конструктор**: Конструктор должен быть приватным, чтобы предотвратить создание новых экземпляров извне

4. **Lazy initialization**: Экземпляр должен быть создан только при первом вызове метода `getInstance()`, а не заранее
