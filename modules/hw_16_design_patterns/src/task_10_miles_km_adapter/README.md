# Задача 10: Адаптер для конвертации миль в километры

## Описание

В проекте есть система, которая работает с мильными единицами (например, старая система), но новая система должна использовать километры. Нужно создать адаптер, который будет преобразовывать мили в километры, чтобы новая система могла работать с ними, не изменяя её логику.

## Требования

1. **Интерфейс `Distance`**: Этот интерфейс будет использоваться для работы с расстоянием в разных системах единиц (миль и километров)

2. **Классы `Miles` и `Kilometers`**: Эти классы будут реализовывать интерфейс `Distance`, представляя работу с милями и километрами соответственно

3. **Класс `MilesToKilometersAdapter`**: Этот адаптер будет преобразовывать мильные единицы в километры, чтобы система могла работать с километрами, несмотря на то, что она изначально использует мили
