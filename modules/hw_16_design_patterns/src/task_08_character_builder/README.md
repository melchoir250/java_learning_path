# Задача 8: Builder для создания персонажей в игре

## Описание

В игре игрок создаёт персонажа, задавая его параметры, такие как здоровье, урон, броня и магия. Паттерн Builder поможет организовать создание персонажа, позволяя задавать его параметры поэтапно и не перегружать конструктор класса `Character`.

## Требования

1. **Класс `Character`**: Этот класс представляет персонажа, который содержит параметры, такие как здоровье, урон, броня и магия

2. **Класс `CharacterBuilder`**: Строитель для создания персонажа. Он будет предоставлять методы для задания каждого параметра персонажа. Каждый метод будет возвращать сам объект строитель, что позволит использовать цепочку вызовов

3. **Класс `Game`**: Класс игры, который будет использовать строитель для создания персонажей. Он будет работать с `CharacterBuilder`, чтобы создавать персонажей
