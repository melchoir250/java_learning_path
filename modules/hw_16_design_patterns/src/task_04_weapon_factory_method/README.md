# Задача 4: Фабричный метод для оружия

## Описание

В этой задаче нам нужно создать систему для создания различных видов оружия в игре (например, мечи, луки и пистолеты).
Все оружие будет иметь общий интерфейс, но конкретные реализации оружия будут различаться. Мы будем использовать
фабричный метод, чтобы централизованно создавать объекты оружия.

## Требования

1. **Интерфейс `Weapon`**: Интерфейс, который определяет общие методы для всех типов оружия, например, `attack()`

2. **Конкретные классы `Sword`, `Bow`, `Gun`**: Каждый класс реализует интерфейс `Weapon` и предоставляет свою
   реализацию метода `attack()`

3. **Фабричный метод в классе `WeaponFactory`**: Фабрика будет иметь метод `createWeapon()`, который будет создавать
   объекты оружия. Конкретные фабрики (например, `SwordFactory`, `BowFactory`, `GunFactory`) будут реализовывать метод
   `createWeapon()`
