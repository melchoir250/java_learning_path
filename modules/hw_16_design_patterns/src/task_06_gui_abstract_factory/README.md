# Задача 6: Абстрактная фабрика графических элементов

## Описание

Приложение должно работать одинаково на разных платформах (Windows и MacOS), но выглядеть по-разному, соответственно
стилям каждой платформы. Мы будем использовать абстрактную фабрику для создания различных графических элементов (
например, кнопок, окон и меню), которые будут выглядеть по-разному в зависимости от платформы.

## Требования

1. **Интерфейс `GUIFactory`**: Этот интерфейс будет объявлять методы для создания различных элементов интерфейса,
   например, `createButton()`, `createWindow()`, `createMenu()`

2. **Конкретные фабрики `WindowsFactory` и `MacFactory`**: Эти фабрики реализуют интерфейс `GUIFactory` и создают
   элементы интерфейса в стиле Windows и MacOS соответственно

3. **Интерфейсы `Button`, `Window`, `Menu`**: Эти интерфейсы будут определять общие методы для элементов интерфейса,
   такие как `click()` для кнопки, `draw()` для окна и `select()` для меню

4. **Конкретные классы `WindowsButton`, `MacButton`, `WindowsWindow`, `MacWindow`, `WindowsMenu`, `MacMenu`**: Эти
   классы будут реализовывать интерфейсы для различных элементов интерфейса, предоставляя платформенно-специфичные
   реализации
