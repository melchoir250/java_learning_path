# Задача 12: Фасад для системы "Умный дом"

## Описание

В системе "Умный дом" есть несколько устройств, которые управляют:
- Светом (включить/выключить)
- Кондиционером (включить/выключить)
- Системой безопасности (включить/выключить)

Клиенту нужно предоставить единый интерфейс для управления (включение/выключение) всеми этими устройствами, скрыв детали реализации каждого из них. Используем фасад, который объединит все эти операции в один интерфейс.

## Требования

1. **Классы устройств**:
   - `Light` — управление светом (методы `turnOn()`, `turnOff()`)
   - `AirConditioner` — управление кондиционером (методы `turnOn()`, `turnOff()`)
   - `SecuritySystem` — управление безопасностью (методы `activate()`, `deactivate()`)

2. **Класс `SmartHomeFacade`**: Этот класс будет объединять все устройства и предоставлять простые методы для включения и выключения всего сразу
