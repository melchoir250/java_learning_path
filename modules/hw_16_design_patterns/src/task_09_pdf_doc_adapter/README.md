# Задача 9: Адаптер для работы с PDF и DOC

## Описание

У нас есть два типа файлов:
- PDF-файл, который должен обрабатываться системой, но она работает только с DOC
- Необходимо создать адаптер, который позволит работать с файлами обоих форматов, конвертируя их при необходимости

Задача — создать интерфейс, который будет принимать файлы с расширением PDF или DOC, а также адаптер, который будет конвертировать один формат в другой.

## Требования

1. **Интерфейс `DocumentProcessor`**: Это интерфейс, который будет содержать метод `process()`, с помощью которого мы будем обрабатывать файлы

2. **Классы `PDFProcessor` и `DOCProcessor`**: Эти классы реализуют интерфейс `DocumentProcessor` и реализуют логику обработки каждого типа документа

3. **Класс `DocumentAdapter`**: Этот класс адаптирует метод обработки одного типа документа в другой, конвертируя формат (например, PDF в DOC)
