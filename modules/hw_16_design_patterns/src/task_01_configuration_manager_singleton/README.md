# Задача 1: Singleton для управления конфигурацией приложения

## Описание

В приложении необходимо создать класс `ConfigurationManager`, который будет управлять настройками приложения, такими
как:

- Параметры подключения к базе данных (например, URL базы данных, имя пользователя, пароль)
- Путь к папке для хранения файлов
- Настройки логирования (например, уровень логирования, путь к лог-файлу)

Класс `ConfigurationManager` должен быть реализован по паттерну Singleton, чтобы в приложении был только один экземпляр
этого класса, который будет предоставлять доступ к конфигурационным данным.

## Требования

1. **Единственный экземпляр**: В системе должен быть только один экземпляр `ConfigurationManager`, который
   инициализируется при первом обращении

2. **Глобальный доступ**: К объекту `ConfigurationManager` можно будет получить доступ в любой части приложения через
   метод `getInstance()`

3. **Приватный конструктор**: Конструктор должен быть приватным, чтобы предотвратить создание экземпляров извне

4. **Lazy initialization**: Экземпляр должен создаваться только при первом запросе, а не заранее
