# Задача 5: Абстрактная фабрика мебели

## Описание

В мебельном магазине предлагаются два стиля мебели: современный и классический. Клиент должен выбрать только стиль, а
конкретные элементы мебели (например, стулья и столы) должны подбираться автоматически в зависимости от выбранного
стиля. Мы будем использовать абстрактную фабрику, чтобы разделить создание современных и классических элементов мебели.

## Требования

1. **Интерфейс `FurnitureFactory`**: Этот интерфейс будет объявлять методы для создания различных типов мебели (
   например, стульев и столов)

2. **Конкретные фабрики `ModernFurnitureFactory` и `ClassicFurnitureFactory`**: Эти фабрики реализуют интерфейс
   `FurnitureFactory` и создают объекты мебели в своём стиле (современный или классический)

3. **Интерфейсы `Chair` и `Table`**: Эти интерфейсы будут определять общие методы для стульев и столов, например,
   `sitOn()` для стула и `use()` для стола

4. **Конкретные классы `ModernChair`, `ClassicChair`, `ModernTable`, `ClassicTable`**: Эти классы реализуют
   соответствующие интерфейсы для стульев и столов в разных стилях
