# Задача 11: Фасад для управления дверью

## Описание

В нашей системе есть несколько операций для управления дверью:
- Открытие двери
- Закрытие двери
- Блокировка двери

Каждая операция реализована в своём классе. Задача — создать фасад, который будет объединять эти операции и предоставлять простой интерфейс для работы с дверью.

## Требования

1. **Операции управления дверью**:
   - `DoorOpen` — операция для открытия двери
   - `DoorClose` — операция для закрытия двери
   - `DoorLock` — операция для блокировки двери

2. **Класс `DoorFacade`**: Этот класс будет объединять все операции и предоставлять единый метод для работы с дверью (открыть, закрыть или заблокировать)
